# Gestion d'un Restaurant - Base de données MySQL

Projet réalisédans le cadre du cours INFO0303 (L2 Informatique, URCA).

## Objectif
Conception et implémentation d'une base de données relationnelle pour gérer les opérations d'un restaurant : réservations, commandes, menus, stocks, fournisseurs.

## Méthodologie
Approche MERISE complète : analyse des besoins, MCT, MCD, MLD, normalisation (3NF), puis implémentation sous MySQL.

## Contenu
- `creation_bdd.sql` : script de création des tables et jeu d'essai
- `requetes.sql` : requêtes SQL (jointures, requête imbriquée, calcul, planning, soustraction et division relationnelle)

## Outils utilisés
Looping (modélisation MERISE), Wampserver, MySQL, phpMyAdmin
